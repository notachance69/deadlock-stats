Deadlock Stats Exporter

Pulls a player's match history from the free public Deadlock API and lets you export it as CSV or JSON.

Check 1: open the raw API data for this account. If you see a page of text starting with [{"account_id", the API is fine and the problem is how this file was opened. On iPhone, the Files app preview blocks internet requests, so open the file on a computer, or use Check 2.

Check 2 (works anywhere): on that raw API page, select all, copy, paste it below and tap Use pasted data.
